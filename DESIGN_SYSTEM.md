# Design system log

Every token or component change in NovaKit Lite: what changed, why (one line), and the file it lives in. Newest first. The decisions behind each change are in `docs/01-system-audit.md`.

| 16 Oct 2026 | BottomSheet is a real dialog: `role="dialog"`, `aria-modal`, named by a required `title` (its `<h2>`). ## Reviewer scaffolding (not NovaKit)

Components that live in `src/review/`, beside the phone frame. They are never exported from `src/novakit/` and never used by a screen. They use existing tokens only.

| Date | What changed | Why | File |
|---|---|---|---|
| 17 Oct 2026 | From 768px (`md`) the phone and panel sit side by side in a row, centred together; the panel fills an `aside` stretched to the phone's height (absolute, inset 0), so its content never makes the page taller. Below 768px the panel is a push-down drawer: a secondary `Button` "Reviewer controls" (`aria-expanded`, `aria-controls`) shown above the phone, opening the panel (capped at `max-h-96`, same inner scroll) downwards so it pushes the phone down and never covers it. The aside stays after the phone in the DOM (`order-first` only on narrow screens), so Tab reaches the phone first. Choosing a state closes the drawer and returns focus to its button. The panel's visible title is screen-reader-only on narrow screens, where the button says it | The panel hung off the phone's right edge and needed a window about 1,060px wide; it now fits from 768px and is reachable on narrower screens without covering the phone's actions. No new component | `src/App.jsx`, `src/review/ReviewerState.jsx` |
| 17 Oct 2026 | Every state has a link, `?state=S1` … `S12`, `S12-delay` (`S6`, `S7` open S4 with that outcome; `S5` opens S4; anything else opens S1). The app opens on the linked state, and the URL follows the current state with `replaceState`, so a reload keeps it and Back doesn't step through states. The S5–S7 entry also gets `aria-current` | The README and write-up can link straight to a state, and a reload no longer drops the reviewer back to the start | `src/review/reviewStates.js`, `src/review/ReviewerState.jsx`, `src/App.jsx` |

## Exceptions to `npm run check`

| Exception | Why | Where |
|---|---|---|
| Tailwind's `white`, `black` and `transparent` | They're absolutes, not palette choices: white surfaces and text on fills, black only as the base of the scrim, transparent for resets. A token would only rename them | `scripts/check-tokens.mjs` |
| Phone frame size and radius, page backdrop | Scaffolding around the prototype, not the product | `scripts/check-allowlist.json` |
| `src/review/novakit-v0/` borders | Frozen starter copy for before/after. Never edited, never imported | `scripts/check-allowlist.json` |
